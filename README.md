# 🐱 Catculator (Kalkulator Umur Kucing)

Sebuah aplikasi Android sederhana yang berfungsi untuk mengonversi umur kucing menjadi ekuivalen umur manusia. Aplikasi ini dibuat menggunakan bahasa pemrograman **Kotlin** dan mengusung antarmuka pengguna (UI) yang modern menggunakan **Material Design**.

---

## ✨ Fitur Utama
* **Input Interaktif:** Menerima input umur kucing berupa angka.
* **Kalkulasi Akurat:** Mengonversi umur kucing ke umur manusia menggunakan rasio standar (dikali 7).
* **Validasi Input:** Mencegah aplikasi *crash* jika pengguna menekan tombol tanpa memasukkan angka.
* **UI/UX Modern:** Desain antarmuka yang rapi dengan sudut membulat (*rounded corners*), palet warna hangat, dan latar belakang gradasi (*custom drawable*).

## 🛠️ Teknologi yang Digunakan
* **Bahasa Pemrograman:** Kotlin
* **Desain Tampilan:** XML
* **Komponen UI:** * `TextInputEditText` (Input)
  * `MaterialButton` (Tombol Aksi / onClick)
  * `TextView` & `CardView` (Output Visual)
* **IDE:** Android Studio
